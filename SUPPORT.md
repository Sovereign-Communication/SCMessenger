# SCMessenger Support

Status: Active
Last updated: 2026-07-24

SCMessenger's current public development line is **v0.4.0** (`Cargo.toml:9`; the
working tree is ahead of the last tagged release, `v0.4.0-rc.1`, and no GitHub
Release object exists for it yet), working
toward **v1.0.0**. Sequencing for the v1.0.0 work is tracked in
`HANDOFF/V1_0_0_EXECUTION_PLAN.md`.

## Where to Ask for Help

### Report a bug

Use the GitHub bug-report template and include:

- affected platform(s),
- the version/commit you tested,
- reproduction steps,
- logs or screenshots when available.

### Report a documentation problem

Use the GitHub documentation template for stale, missing, or unclear docs.

### Request a feature or propose future work

Use the feature-request template. If the request is v1.0.0 scope rather than a
fix against the current v0.4.0 line, say so explicitly.

### Ask a general question

Open a GitHub issue. GitHub Discussions is not enabled on this repository.

### Report a security vulnerability

Do **not** open a public issue. Follow `SECURITY.md` and use GitHub's private
vulnerability reporting flow (repository **Security** tab, **Report a
vulnerability**).
