## One finding worth more than the diff

`scripts/docs_sync_check.sh` **passes on all of the above**. It validates
`Status:`/`Last updated:` headers, machine-local paths, and markdown
`[text](target)` links for a fixed file list -- it does not test the backticked
path claims scattered through `DOCUMENT_STATUS_INDEX.md`, which is exactly how
nine stale rows and a reference to a nonexistent section survived in the
document whose entire job is to say which documents are current. If this class
is worth closing permanently, the cheap version is to extend that script over
the index's backticked tokens; that is a follow-up, not part of this ticket.
